# 要约三则

合同法课堂用的互动讲解页：三则日常交易场景，判断每场里谁是要约人、谁是被要约人。

## 使用

双击 `index.html` 即可打开，无需联网、无需构建。

- 点「要约人」「受要约人」两行，揭晓答案
- 两个都揭晓后，右下角出现「下一场」
- 键盘：`→` / `PageDown` 下一场，`←` 回看，`R` 重来（支持翻页笔）
- 第三场结束可「从头再看」

## 内容

| 场景 | 台词 | 要约人 | 受要约人 |
|---|---|---|---|
| 食堂窗口 | 「阿姨，我要一份 12 元的红烧肉套餐。」 | 学生 | 食堂阿姨 |
| 手机店 | 「这部标价 6500 的手机有现货吗？有现货的话我现在就买。」 | 顾客 | 手机店老板 |
| 直播间 | 「家人们，这款口红专柜 300，今天上链接只要 99……」 | 主播 | 消费者 |

## 部署

纯静态，把整个目录作为发布目录即可（Netlify 拖拽上传或连接本仓库）。

```bash
# 本地预览
python -m http.server 8080
```
